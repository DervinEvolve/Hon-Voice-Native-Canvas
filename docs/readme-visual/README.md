# README capture

The README displays the complete original `docs/assets/hon-speech-generated-image.png` directly. It has no added speech panel, replacement controls, window chrome, or invented transcript. The scene and 3D captures remain below it.

The README does not use this folder. This optional [Stageshow](https://github.com/benjitaylor/skills/tree/main/stageshow) authoring source simply displays that same capture. Copy this folder to the kit's `examples/readme-hon`, copy the screenshot to `playground/public/readme-captures/hon-image.png`, then open `?capture=readme-hon&still=1`. The image scales proportionally at every width. The app does not import this renderer.

The Stageshow-derived source retains its MIT notice in `LICENSE.stageshow.txt`. Captures and third-party content retain their own terms. No Colorfigures code or assets are used.
