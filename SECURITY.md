# Security reports

Please report Hon vulnerabilities privately to this repository's maintainer.

Use **Report a vulnerability** in the repository's GitHub Security tab if it is available. Otherwise, ask the maintainer for a private contact route without including vulnerability details, credentials, or exploit instructions in a public issue.

This is an experimental project. There is no promised response time or production security guarantee.

Keep service credentials, database URLs, auth tokens, private projects, and user media out of issues, screenshots, and pull requests. Revoke exposed credentials through their provider. Removing the current file does not remove earlier commits, other branch tips, or old deployments.
